Privacy Policy

Last updated: 2 September 2026

This policy covers the website danribes.github.io and the personal software applications operated by Daniel Ribes under this domain, including tools that connect to Google APIs (such as the YouTube Data API) using OAuth credentials associated with this domain (the “Applications”).

Who uses these Applications

The Applications are personal productivity tools operated and used by their owner to manage the owner's own accounts and content (for example, uploading videos to the owner's own YouTube channel). They are not distributed to, or intended for use by, the general public.

Data collected by this website

This website is a static site hosted on GitHub Pages. It sets no cookies of its own, runs no analytics operated by me, and collects no personal information from visitors. GitHub, as the hosting provider, may log standard technical data (such as IP addresses) as described in the GitHub Privacy Statement.

Data accessed via Google APIs

When the Applications connect to Google services, they do so exclusively with the account owner's own authorization and act only on the owner's own data (for example, video uploads, titles, and descriptions on the owner's YouTube channel). Specifically, the Applications:

  • do not collect, store, or process personal data belonging to third parties;
  • do not sell, share, or transfer Google user data to any third party;
  • do not use Google user data for advertising;
  • store OAuth tokens locally on the owner's own machine and nowhere else.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The Applications use YouTube API Services; by using them, the owner also agrees to the YouTube Terms of Service and the Google Privacy Policy.

Data retention and deletion

Locally stored credentials can be revoked at any time from the Google account's third-party access settings, which immediately invalidates the Applications' access.
